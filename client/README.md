# Evidra Frontend Client

The frontend application for the Evidra AI-Powered Placement Intelligence Platform, built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Modern React 19 & TypeScript**: Strict type safety and component model.
- **Tailwind CSS**: Modern utility-first styling with dark mode aesthetics.
- **Vite Bundler**: Instant Hot Module Replacement (HMR) and optimized production builds.
- **Health Verification**: Real-time status checking with backend Express API.
- **Vercel Deployment**: Pre-configured SPA rewrite rules via `vercel.json`.

## Scripts

- `npm run dev` - Launch Vite development server on `http://localhost:5173`
- `npm run build` - Type-check and create production bundle in `dist/`
- `npm run preview` - Preview production build locally
- `npm run typecheck` - Run TypeScript compiler checks
